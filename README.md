# K-Means Visualizer Interactif

🔹 **K-Means Visualizer** est un outil interactif pour visualiser l'algorithme **K-Means** pas à pas sur différents types de nuages de points.  

Avec ce projet, vous pouvez :

- Générer des nuages de points selon différentes distributions : Gaussienne, Uniforme, Cercle, Anneau, Spirale.  
- Visualiser l’algorithme K-Means étape par étape, avec initialisation aléatoire ou K-Means++.  
- Observer la formation des clusters via des animations interactives.  

L’interface graphique est réalisée avec **Tkinter** et **ttkbootstrap**, et les graphiques avec **matplotlib**.

---

## Exécution

### Sur Windows

Si vous utilisez Windows, un exécutable est fourni dans le dossier `dist` :

dist/kmeans_visualizer.exe

Il suffit de double-cliquer sur l’exécutable ou de le lancer depuis la ligne de commande pour démarrer l’application.

### Sur Linux (ou depuis le code source)
Pour Linux, ou si vous voulez exécuter le projet depuis le code source Python :

Assurez-vous d’avoir Python 3.8+ installé.
Si c'est bon, lancez cette ligne de code :  

python kmeans_visualizer.py
